# Никб вирус

Страшный вирус

## Возможности

- Несколько типов окон: экран копирования, предупреждение и терминал.
- Движение окон по экрану, включая блуждание, рывки и реакцию на курсор.
- Встроенные изображения и звуковые эффекты; отдельные файлы ресурсов для запуска не нужны.
- Окна отображаются поверх других и не забирают фокус ввода.

## Запуск

Скачайте `nikb_virus.exe` из раздела Releases или соберите программу самостоятельно. При запуске консольная сцена открывается сразу, а всплывающие окна появляются примерно через 30 секунд. По умолчанию они могут появляться на всех подключённых дисплеях; одновременно открыто не более шести окон.

Чтобы показывать окна только на одном дисплее, укажите `--display` и его номер:

```text
nikb_virus.exe --display 3
```

В этом примере окна и консольная сцена будут размещаться только на дисплее 3. Нумерация идёт слева направо; если дисплеи стоят один над другим, верхний считается первым.

Для завершения в обычном режиме нажмите `Ctrl+Shift+Q`. Сочетание сработает, если оно не занято другой программой.

## Сборка

Встроены шесть звуковых эффектов в формате OGG.

Для сборки требуется Windows и Rust с MSVC toolchain (`x86_64-pc-windows-msvc`).

```bash
cargo build --release
```

Готовый файл появится здесь:

```text
target/release/nikb_virus.exe
```

## Остановка

Нажмите `Ctrl+Shift+Q`. Если это сочетание занято другой программой, закройте приложение через Диспетчер задач.
